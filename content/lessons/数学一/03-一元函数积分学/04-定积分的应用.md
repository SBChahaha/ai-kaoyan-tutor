> **对应考纲**：掌握用定积分表达和计算平面图形面积、旋转体体积、平面曲线弧长、旋转曲面侧面积及物理应用（压力、做功、引力等）；会用"微元法"建立积分表达式。
> **本课目标**：定积分应用的本质是一个思想——**微元法**（取微元、近似、积分）。面积、体积、弧长、做功全是同一个套路。掌握微元法，应用题的 90% 都能拿下。

## 0 启发：先回答一个问题

**为什么旋转体体积是 $\pi\int_a^b f^2(x)dx$，而不是 $\pi\int_a^b f(x)dx$ 的什么组合？** 因为微元法：把旋转体切成无穷多个薄圆片，第 $x$ 处的薄片厚度 $dx$、半径 $f(x)$、体积 $dV = \pi f^2(x)dx$——**把所有薄片加起来就是积分**。记住这个思想，所有公式都不用背，自己推。

## 1 微元法（本课的灵魂，先学思想）

> **微元法四步**：
> 1. **取微元**：在区间 $[a,b]$ 上取一小段 $[x, x+dx]$
> 2. **近似**：把这一小段上的量 $dU$ 近似为"简单几何体"（矩形/圆片/直段）——$dU = f(x)dx$（**高 × 宽**）
> 3. **积分**：$U = \int_a^b f(x)dx$
> 4. **检验**：看结果量纲/几何是否合理
>
> 口诀：**切小块、近似直、加起来、取极限**。

## 2 平面图形面积（3 种情况全背）

**情况一（直角坐标，$x$ 型）**：由曲线 $y = f(x)$、$y = g(x)$（$f \ge g$）与 $x = a$、$x = b$ 围成：
> $$S = \int_a^b [f(x) - g(x)]\,dx$$
> **上减下**。例：$y = x^2$ 与 $y = \sqrt{x}$ 围成的面积：
> 先求交点：$x^2 = \sqrt{x} \Rightarrow x = 0, 1$；$S = \int_0^1 (\sqrt{x} - x^2)dx = \dfrac{2}{3} - \dfrac{1}{3} = \dfrac{1}{3}$。

**情况二（$y$ 型）**：由曲线 $x = \varphi(y)$、$x = \psi(y)$（$\varphi \ge \psi$）与 $y = c$、$y = d$ 围成：
> $$S = \int_c^d [\varphi(y) - \psi(y)]\,dy$$
> **右减左**。什么时候用 $y$ 型？——函数是 $x = f(y)$ 形式（如 $x = y^2$）或 $y$ 型计算更简单时。

**情况三（极坐标）**：由 $r = r(\theta)$、$\theta = \alpha$、$\theta = \beta$ 围成：
> $$S = \frac{1}{2}\int_\alpha^\beta r^2(\theta)\,d\theta$$
> **推导**：扇形面积公式 $\dfrac{1}{2}r^2\Delta\theta$ 的微元版。例：心形线 $r = 1 + \cos\theta$ 面积 $= \dfrac{1}{2}\int_0^{2\pi}(1+\cos\theta)^2 d\theta = \dfrac{3\pi}{2}$。

## 3 旋转体体积（2 种方法）

**方法一（圆片法，绕 $x$ 轴）**：$y = f(x)$ 与 $x$ 轴、$x = a$、$x = b$ 围成的图形绕 $x$ 轴旋转：
> $$V = \pi\int_a^b f^2(x)\,dx$$
> **微元**：$dV = \pi f^2(x)dx$（半径 $f(x)$ 的薄圆片）。
>
> 绕 $y$ 轴旋转（**壳法/柱壳法**）：
> $$V = 2\pi\int_a^b x\,f(x)\,dx$$
> **微元**：$dV = 2\pi x \cdot f(x)dx$（半径 $x$、高 $f(x)$ 的薄壳，展开是 $2\pi x f(x)$ 的矩形）。
>
> **记忆**：绕 $x$ 轴用圆片（半径是函数值），绕 $y$ 轴用柱壳（半径是 $x$）。

**方法二（垫片法，两曲线之间）**：$y = f(x) \ge g(x) \ge 0$ 围成图形绕 $x$ 轴：
> $$V = \pi\int_a^b [f^2(x) - g^2(x)]\,dx$$
> **外半径平方减内半径平方**（空心垫片）。⚠️ 不是 $\pi\int(f-g)^2 dx$！**平方差不是差的平方**——这是高频错误。

## 4 平面曲线弧长（3 种形式）

> **直角坐标**：$y = f(x)$，$a \le x \le b$：
> $$s = \int_a^b \sqrt{1 + [f'(x)]^2}\,dx$$
>
> **参数方程**：$x = x(t), y = y(t)$，$\alpha \le t \le \beta$：
> $$s = \int_\alpha^\beta \sqrt{[x'(t)]^2 + [y'(t)]^2}\,dt$$
>
> **极坐标**：$r = r(\theta)$：
> $$s = \int_\alpha^\beta \sqrt{r^2 + (r')^2}\,d\theta$$
>
> **微元本质**：弧长微元 $ds = \sqrt{(dx)^2 + (dy)^2}$——**勾股定理的微元版**，三种形式全是它展开的。

**旋转曲面侧面积**（绕 $x$ 轴）：
> $$S = 2\pi\int_a^b |f(x)|\sqrt{1 + [f'(x)]^2}\,dx$$
> **微元**：$dS = 2\pi|f(x)|ds$（半径为 $|f(x)|$ 的薄环带）。

## 5 物理应用（3 大类型）

**类型一（变力做功）**：力 $F(x)$ 沿 $x$ 轴从 $a$ 到 $b$：
> $$W = \int_a^b F(x)\,dx$$
> **例**：弹簧从自然长度拉长 $L$，$F = kx$：$W = \int_0^L kx\,dx = \dfrac{1}{2}kL^2$。

**类型二（液体压力）**：平板竖直浸入液体，液面下 $y$ 处的压强 $p = \rho g y$：
> $$F = \int \rho g y \cdot dS$$
> **例**：求等腰三角形闸门一侧所受压力——取水平薄条 $dS = 宽(y)dy$，压强 $\rho gy$，$F = \rho g\int y \cdot 宽(y)dy$。
> **套路**：**压强是深度的函数，面积微元要取"水平条"**（同一深度压强相同）。

**类型三（引力）**：细杆对质点的引力（数一偶尔考）：
> **套路**：取微元 $dm = \lambda dx$，用万有引力公式 $dF = G\dfrac{m\,dm}{r^2}$，按对称性抵消分量再积分。

## 6 例题精讲

**例 1（面积）**：求 $y = x^2$ 与 $y = 2x$ 围成的面积。
**解**：交点 $x = 0, 2$。$S = \int_0^2 (2x - x^2)dx = \left[x^2 - \dfrac{x^3}{3}\right]_0^2 = 4 - \dfrac{8}{3} = \dfrac{4}{3}$。

**例 2（旋转体）**：$y = \sqrt{x}$，$x \in [0, 1]$，绕 $x$ 轴旋转一周的体积。
**解**：$V = \pi\int_0^1 x\,dx = \dfrac{\pi}{2}$。

**例 3（柱壳）**：$y = x^2$（$0 \le x \le 1$）绕 $y$ 轴旋转。
**解**：$V = 2\pi\int_0^1 x \cdot x^2 dx = 2\pi \cdot \dfrac{1}{4} = \dfrac{\pi}{2}$。

**例 4（垫片法陷阱）**：$y = x$ 与 $y = x^2$ 围成图形绕 $x$ 轴。
**解**：$V = \pi\int_0^1 [x^2 - x^4]dx = \pi\left(\dfrac{1}{3} - \dfrac{1}{5}\right) = \dfrac{2\pi}{15}$。**必须平方差，不是 $(\Delta y)^2$**。

**例 5（弧长）**：求 $y = \dfrac{2}{3}x^{3/2}$ 在 $[0, 1]$ 上的弧长。
**解**：$y' = x^{1/2}$，$s = \int_0^1 \sqrt{1+x}\,dx = \dfrac{2}{3}(2\sqrt{2} - 1)$。

**例 6（物理做功）**：将底半径 $R$、高 $H$ 的圆锥形水塔中的水全部抽到塔顶，做功？
**解**：取距塔底 $y$ 处厚度 $dy$ 的薄层：半径 $r(y) = R\left(1 - \dfrac{y}{H}\right)$，体积 $dV = \pi r^2 dy$，质量 $\rho dV$，提升高度 $H - y$：
$W = \rho g\pi\int_0^H r^2(y)(H - y)dy = \rho g\pi R^2\int_0^H \left(1 - \dfrac{y}{H}\right)^2 (H-y)dy = \dfrac{\rho g\pi R^2 H^2}{12}$。
**套路：微元法 + 变量统一（都用 $y$ 表示）**。
