> **对应考纲**：理解原函数与不定积分的概念；掌握不定积分的基本性质与基本积分公式；掌握换元积分法与分部积分法；会求有理函数、三角函数有理式、简单无理函数的积分。
> **本课目标**：积分 = 微分的逆运算。求导有公式表，积分没有——所以积分靠"技巧"，技巧就两个半：换元、分部、拆项。

## 0 启发：先回答一个问题

**$\int \dfrac{1}{x}\,dx = \ln|x| + C$，为什么绝对值不能省？**（因为 $(\ln|x|)' = \dfrac{1}{x}$ 对 $x > 0$ 和 $x < 0$ 都成立——$x<0$ 时 $\ln|x| = \ln(-x)$，求导得 $\dfrac{1}{x}$。省掉绝对值定义域就错了。）

## 1 原函数与不定积分

> **定义**：若 $F'(x) = f(x)$，则称 $F(x)$ 是 $f(x)$ 的一个**原函数**。$f(x)$ 的全体原函数 $F(x) + C$ 称为**不定积分**，记作 $\int f(x)\,dx$。
>
> **原函数存在定理**：连续函数必有原函数（注意：有原函数不一定连续，但考研范围内记住"连续 ⟹ 有原函数"即可）。

**三条基本性质（必背）**：
> 1. $\left(\int f(x)\,dx\right)' = f(x)$——先积后导，还原
> 2. $\int f'(x)\,dx = f(x) + C$——先导后积，差常数
> 3. 线性：$\int [af(x) + bg(x)]\,dx = a\int f(x)\,dx + b\int g(x)\,dx$

> ⚠️ **积分常数 C 不能丢**——丢了就错。考研选择题最爱问"$F(x)$ 与 $G(x)$ 都是 $f(x)$ 的原函数，则 $F(x) - G(x) = ?$"答案：常数。

## 2 基本积分公式表（由求导公式倒过来背）

$$\int x^\alpha\,dx = \frac{x^{\alpha+1}}{\alpha+1} + C\ (\alpha \ne -1), \qquad \int \frac{1}{x}\,dx = \ln|x| + C$$

$$\int e^x\,dx = e^x + C, \qquad \int a^x\,dx = \frac{a^x}{\ln a} + C$$

$$\int \sin x\,dx = -\cos x + C, \qquad \int \cos x\,dx = \sin x + C$$

$$\int \sec^2 x\,dx = \tan x + C, \qquad \int \csc^2 x\,dx = -\cot x + C$$

$$\int \frac{1}{1+x^2}\,dx = \arctan x + C, \qquad \int \frac{1}{\sqrt{1-x^2}}\,dx = \arcsin x + C$$

**必须额外记住的四个（从导数倒推）**：

$$\int \tan x\,dx = -\ln|\cos x| + C, \qquad \int \cot x\,dx = \ln|\sin x| + C$$

$$\int \sec x\,dx = \ln|\sec x + \tan x| + C, \qquad \int \frac{1}{\sqrt{x^2 \pm a^2}}\,dx \text{（反双曲/对数型，遇到再展开）}$$

## 3 第一类换元法（凑微分）——使用频率最高

> 思想：$\int f(g(x))g'(x)\,dx = \int f(u)\,du$（$u = g(x)$）。把 $g'(x)dx$ 整个"凑"成 $du$。
>
> **例 1**：$\int 2x e^{x^2}\,dx$。令 $u = x^2$，$du = 2x\,dx$，原式 $= \int e^u\,du = e^{x^2} + C$。
>
> **例 2**：$\int \dfrac{dx}{1 + 4x^2}$。凑成 $\arctan$ 的形式：$\int \dfrac{dx}{1+(2x)^2} = \dfrac{1}{2}\int \dfrac{d(2x)}{1+(2x)^2} = \dfrac{1}{2}\arctan(2x) + C$。
>
> **常见凑微分模式（条件反射）**：$x\,dx = \dfrac{1}{2}d(x^2)$，$\dfrac{1}{x}dx = d(\ln x)$，$\cos x\,dx = d(\sin x)$，$e^x dx = d(e^x)$，$\dfrac{1}{\sqrt{x}}dx = 2d(\sqrt{x})$。

## 4 第二类换元法（代换）

> 用于根式/三角结构，**反着换**：令 $x = \varphi(t)$ 消去根号。
>
> **三角代换三大件（必背）**：
> | 根式结构 | 代换 | 原理 |
> |---------|------|------|
> | $\sqrt{a^2 - x^2}$ | $x = a\sin t$ | $1-\sin^2 t = \cos^2 t$ |
> | $\sqrt{a^2 + x^2}$ | $x = a\tan t$ | $1+\tan^2 t = \sec^2 t$ |
> | $\sqrt{x^2 - a^2}$ | $x = a\sec t$ | $\sec^2 t - 1 = \tan^2 t$ |
>
> **例 3**：$\int \sqrt{1 - x^2}\,dx$。令 $x = \sin t$：原式 $= \int \cos^2 t\,dt = \dfrac{1}{2}\int(1 + \cos 2t)dt = \dfrac{t}{2} + \dfrac{\sin 2t}{4} + C = \dfrac{\arcsin x}{2} + \dfrac{x\sqrt{1-x^2}}{2} + C$。
> **回代**：用直角三角形（斜边 1，对边 x）把 $\sin 2t = 2\sin t\cos t = 2x\sqrt{1-x^2}$ 换回。
>
> **根式代换**：$\sqrt[n]{ax+b}$ 型令 $t = \sqrt[n]{ax+b}$；$\sqrt{ax^2+bx+c}$ 配方法后归入三角代换。

## 5 分部积分法

> 由乘积求导公式反推：$(uv)' = u'v + uv'$ ⟹ $\int u\,dv = uv - \int v\,du$。
>
> **选 u 的口诀（LIATE 优先级）**：**L**og 对数 > **I**nverse 反三角 > **A**lgebraic 幂函数 > **T**rig 三角 > **E**xponential 指数——**越靠左越当 u**（因为越靠左越难积，先求导变简单）。
>
> **例 4**：$\int x e^x\,dx$。$u = x$（代数），$dv = e^x dx$：原式 $= xe^x - \int e^x\,dx = xe^x - e^x + C$。
>
> **例 5**：$\int \ln x\,dx$。$u = \ln x$（对数），$dv = dx$：原式 $= x\ln x - \int x \cdot \dfrac{1}{x}\,dx = x\ln x - x + C$。
>
> **循环型（经典）**：$\int e^x \sin x\,dx$——分部两次回到自身，移项求解：
> 两次分部得 $I = e^x\sin x - e^x\cos x - I$，故 $I = \dfrac{e^x(\sin x - \cos x)}{2} + C$。

## 6 有理函数积分（拆项大法）

> $\int \dfrac{P(x)}{Q(x)}\,dx$ 的流程：
> 1. **假分式先除**：分子次数 ≥ 分母次数时，多项式除法化整式 + 真分式
> 2. **真分式拆部分分式**：分母因式分解后，每个因子对应一项
> 3. 逐项积分
>
> **例 6**：$\int \dfrac{dx}{x^2 - 1} = \int \dfrac{dx}{(x-1)(x+1)} = \dfrac{1}{2}\int\left(\dfrac{1}{x-1} - \dfrac{1}{x+1}\right)dx = \dfrac{1}{2}\ln\left|\dfrac{x-1}{x+1}\right| + C$。
> **待定系数**：$\dfrac{1}{(x-1)(x+1)} = \dfrac{A}{x-1} + \dfrac{B}{x+1}$，解得 $A = \dfrac{1}{2}$，$B = -\dfrac{1}{2}$。

## 7 例题精讲

**例 7（凑微分综合）**：$\int \dfrac{\ln x}{x}\,dx$。
**分析**：$\dfrac{1}{x}dx = d(\ln x)$，原式 $= \int \ln x\,d(\ln x) = \dfrac{(\ln x)^2}{2} + C$。**看到"函数×其导数"的组合就想到凑微分**。

**例 8（分部 × 换元）**：$\int \arctan x\,dx$。
**分析**：$u = \arctan x$（反三角优先当 u）：原式 $= x\arctan x - \int \dfrac{x}{1+x^2}\,dx = x\arctan x - \dfrac{1}{2}\ln(1+x^2) + C$。

**例 9（换元 → 分部）**：$\int e^{\sqrt{x}}\,dx$。
**分析**：令 $t = \sqrt{x}$，$dx = 2t\,dt$：原式 $= 2\int t e^t\,dt = 2(t-1)e^t + C = 2(\sqrt{x}-1)e^{\sqrt{x}} + C$。
**套路**：根式在指数上 ⟹ 先换元再分部。

**例 10（递推思想）**：$\int \sin^2 x\,dx$。
**分析**：降幂公式 $\sin^2 x = \dfrac{1-\cos 2x}{2}$：原式 $= \dfrac{x}{2} - \dfrac{\sin 2x}{4} + C$。
**必记**：$\int \sin^2 x\,dx$ 与 $\int \cos^2 x\,dx$ 的降幂套路——后面定积分、傅里叶都会用到。
